# Cercle Parfait

Tracez un cercle avec le doigt autour du point central de l'écran.

**Calcul de la précision**

- on mesure la distance minimale (r min) et maximale (r max) du tracé par rapport au centre ;
- écart = (r max − r min) / r max, en % ;
- précision = 100 − écart.

Exemple : un écart de 1 % donne un cercle parfait à 99 %, un écart de 20 % donne 80 %.

Le tracé doit faire un tour complet du centre pour être compté. Le meilleur score est gardé dans le navigateur.

Ouvrir `index.html` dans un navigateur, ou l'activer avec GitHub Pages (Settings → Pages → branche `main`, dossier `/`).
